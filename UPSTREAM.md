# Upstream provenance

SimWing is an independent GPL-3.0 project bootstrapped from
[Kulitorum/LeParagliding](https://github.com/Kulitorum/LeParagliding).

The initial source tree was taken from upstream commit
`497b5632154fb09ef14c4b47943d3fa31a184309` on 2026-08-07. SimWing deliberately
starts with a new root commit rather than copying the upstream commit graph.
The local repository retains this reference remote:

```text
upstream  https://github.com/Kulitorum/LeParagliding.git
```

Inherited copyright notices, the GPL-3.0 license, third-party notices, and
vendor-specific provenance records remain with the corresponding source. In
particular, see `third_party/xflr5/PROVENANCE.md`, `third_party/libf2c`, and
`src/softwing/README.md`.

The initial SimWing root contains the upstream tracked source plus the SimWing
identity, architecture, and documentation changes. Personal design files,
local fixtures, build output, and the private planning transcript were not
included in the public repository.
